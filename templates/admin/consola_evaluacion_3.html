4. Ficha Técnica para Defensa

Arquitectura Desacoplada: El frontend solicita datos asíncronamente vía fetch() a los endpoints de la API, separando la capa de presentación de la lógica de negocio y persistencia en el backend.
Autenticación Stateless (JWT): No se mantiene estado de sesión en memoria del servidor. Cada petición incluye su token firmado criptográficamente con algoritmo HS256, permitiendo escalabilidad horizontal.
Serialización Explícita: Se prohibió el uso de fields = '__all__' para evitar la exposición inadvertida de datos internos y prevenir inyecciones silenciosas de campos.
Seguridad de Credenciales: Las claves críticas (SECRET_KEY, credenciales de BD) están aisladas en el archivo .env y estrictamente excluidas del repositorio mediante .gitignore.
